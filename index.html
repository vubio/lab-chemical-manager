TOOLS / EXPERIMENT DESIGN

Plate layout

Plan plating and label wells independently of chemical preparation and dosing. Save layouts for later editing.

Move labels: click the first well, then Shift-click the last to select consecutive wells (A12 continues to B1). The selected block has a clear outline and a count above. Drag any highlighted well to see the final arrangement before release; occupied wells shift to make room, never swap. Selection: Ctrl/⌘-click toggles wells; drag to select an area. Press Esc to cancel a drag. Double-click a well to open its label editor, or select multiple wells and click Edit / label selected wells to mark controls such as “Media only”. Clear selected labels removes just the selected assignments; Delete/Backspace also works while a selected well has keyboard focus.

GitHub data synchronization

      
Synchronize your chemical inventory, preparation/dosing history, templates, and plate layouts through vubio/lab-chemical-manager on the separate labchem-data branch.

      
Public GitHub repository. Anything uploaded here, including reagent lists, experimental plans and notes, can be viewed publicly. Do not sync confidential, unpublished, patient-related, or sensitive research information to this repository.

      
On GitHub, create a fine-grained personal access token, restricted to vubio/lab-chemical-manager with Contents: Read and write. This token remains in your browser and is never uploaded in your data file.
