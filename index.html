TOOLS / EXPERIMENT DESIGN

Plate layout

Plan plating and label wells independently of chemical preparation and dosing. Save layouts for later editing.

Select mode: drag to select a rectangle; Ctrl/⌘ + drag to add areas; Alt + drag to subtract. Move labels: switch modes and drag a label to move or swap it. Shift + drag a label also moves it in Select mode. Double-click a well to edit its text.

Rename any factor and enter values separated by commas, semicolons, or new lines. The first factor is the most prominent label. Use arrows to change priority. Leave unused factors blank.
